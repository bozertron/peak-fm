# Peak Rentals Ticket Directory

This directory is the preservation-first implementation backlog for Peak Rentals, synthesized from the five source documents and research-agent waves.

## Structure

- `source-index.md` — source documents and governing principles
- `wave-1/` — specialist research outputs: architecture, trust/communications, map/UX, QA/operations, and delivery planning
- `wave-2/` — cross-agent synthesis and conflict resolution
- `wave-3/` — final ordered execution backlog and follow-through runbook
- `decisions/` — unresolved product, security, schema, and rollout decisions
- `templates/` — ticket, acceptance-criteria, and verification templates

## Operating Rules

1. Preserve existing production systems; all work is additive unless explicitly approved.
2. Sequence work through schema, trust APIs, communications, map, aesthetic, then gallery phases.
3. Every ticket must include dependencies, acceptance criteria, verification evidence, rollback/mitigation notes, and follow-through checkpoints.
4. Unsafe or contradictory source recommendations must be recorded as decisions rather than silently implemented.
5. No ticket is complete without regression evidence for existing CRUD, payments, search logging, analytics, and authentication.
